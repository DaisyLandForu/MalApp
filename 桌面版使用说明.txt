MalApp 智能研判平台 - Windows 桌面版

1. 双击“MalApp原生窗口版.exe”。
2. 程序会自动启动本地服务，并打开 Windows 独立桌面窗口，不会调用系统浏览器。
3. 关闭桌面窗口后，本次本地服务自动退出。
4. 所有导入数据和研判结果保存在程序旁边的 data 文件夹。
5. 迁移电脑时，复制整个文件夹即可；备份时重点备份 data 文件夹。

数据加载：
- JSON：支持单个对象、对象数组或包含 items 数组的对象。
- JSONL：每行一个 JSON 对象。
- TXT：每行应为一个 JSON 对象。
- 也可以在“数据加载”页面直接粘贴 JSON/JSONL，点击“解析粘贴内容”，再点击“开始导入”。
- Excel：支持 .xlsx 文件。选择文件后点击“读取 Excel”，可设置工作表、表头行、数据开始行和本次传输数量。
- “本次传输数量”由用户自行填写，例如 10、100、1000；程序只读取并保存指定数量。

自动研判：
- 每次导入都会生成一个独立数据批次，本地文件、粘贴数据、Excel 和冲突样本使用同一套批次流程。
- 在“自动研判流水线”中选择刚加载的批次，并填写“本次自动研判数量”。
- 例如加载 100 条、自动研判数量填写 20，程序只研判该批次中的 20 条，剩余 80 条保留为待研判。
- 勾选“数据加载后自动开始”后，文件导入或冲突样本刷新完成会立即按当前数量启动研判。
- 研判过程中显示当前样本、完成进度、成功数量、失败数量和每条结果。
- 批次任务会自动执行四智能体分析、双模型辩论和三引擎协同决策，不需要再手工复制到单样本输入框。
- 点击“暂停”后，程序会等待当前样本完成，再停止领取下一条样本。
- 点击“继续”后，从该任务尚未处理的样本继续，不会重做已完成条目。
- APP 意外关闭时，运行中的任务会在下次启动自动恢复为“已暂停”，可继续执行。
- 相同样本、相同输入特征和相同模型模式再次研判时，直接复用已保存报告，并显示“历史复用”。

Hermes：
- 四个领域分析模块已注册为 Hermes MCP 工具，由一个 Hermes 主管按静态、情报、仿冒、业务四个领域并行委派。
- 顶部会显示“官方 Hermes 运行时”或“Hermes MCP 兼容模式”。
- 当前机器因无法连接 GitHub，尚未安装官方 Hermes 核心；兼容模式仍使用相同 MCP 工具、Skills、主管约束和标准证据块。
- 官方 Hermes 安装后，APP 状态会识别其运行时；四个分析工具和现有双模型/WEC流程无需重写。

冲突样本：
- 点击“刷新冲突样本”会从历史 Engine A/B 结果中重新索引评分差异或标签不一致的样本。
- 刷新数量由页面中的数量输入框控制。
- 刷新结果会形成一个新的“冲突样本批次”，可直接在自动研判流水线中选择并研判。
- 如果当前数据库没有历史引擎数据，刷新结果为 0；需要先导入原来的 data/mvp.db 或引擎检测数据。

刷新数据：
- 点击右上角“刷新数据”后会显示“刷新中...”。
- 完成后右下角显示“数据已刷新”，首页统计、任务、批次、冲突样本和结果同步更新。

旧数据库迁移：
- 将原项目 data/mvp.db 复制到桌面版 data/mvp.db。
- 必须在程序关闭状态下复制，避免数据库文件被占用。

本地模型：
- 顶部“本地 Qwen”开关关闭时，使用规则模式，速度快但辩论文字为规则模板。
- 开关打开且显示“真实模型已启用”时，后续新研判调用本地 Qwen。
- 开关打开但显示“模型不可用，将降级”时，程序会使用规则模式，并在报告中明确标记降级。
- 当前轻量桌面程序复用本机 test1/.venv 中的 torch、transformers、accelerate 和本机 Hugging Face Qwen 模型缓存，不把约 1.5GB 的运行环境与模型权重重复打入 EXE。
- 桌面程序会自动启动隐藏的本地 Qwen 工作进程，通过 127.0.0.1 在本机内部传输提示词和结果，不向外网发送样本。
- 当前 0.5B 模型在 CPU 上完成一条单轮完整辩论约需 6 分钟；批量研判前建议先用 1 条测试，或关闭开关使用快速规则模式。
- 切换模型模式后使用独立报告缓存，不会继续复用另一模式下生成的旧报告。
- 后续服务器模型 API 可通过环境变量继续接入。
